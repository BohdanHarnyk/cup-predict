# ⚽ CupPredict
### Prediction платформа під ЧС-2026 на базі Polymarket Builder Program

---

## Одне речення

Спортивний фронтенд поверх Polymarket з фокусом на ЧС-2026: ставиш на матчі в 3 кліки, продаєш позицію до кінця гри, все прозоро — а ми заробляємо комісію з кожної ставки.

## Проблема

Polymarket вже має десятки ринків по ЧС-2026 з реальною ліквідністю. Але їхній UI зроблений для крипто-трейдерів: складний, холодний, без спортивного контексту.

Мільйони футбольних фанатів, які хотіли б поставити на матч, просто не розберуться — і йдуть до Bet365.

**Ми робимо міст між футбольною аудиторією і ліквідністю Polymarket.**

---

## Рішення

CupPredict — це красивий, простий, мобільний інтерфейс поверх Polymarket. Під капотом — повністю готова інфраструктура: смарт-контракти, ліквідність, oracle, резолюція. Ми робимо тільки UI і маркетинг.

```
Юзер відкриває CupPredict
        ↓
Бачить розклад матчів, live odds, trending ставки
        ↓
Натискає "Поставити на Бразилію" — вводить суму
        ↓
Наш код додає builderCode до ордера
        ↓
Ордер іде на Polymarket CLOB
        ↓
Ми отримуємо % з кожного трейду автоматично
```

## Продукт — що бачить юзер

### Головна
Карточки матчів як у FlashScore: дата, команди, поточні odds, кнопка "Поставити". Без зайвих таблиць і крипто-жаргону.

### Сторінка матчу
- Live odds YES/NO на перемогу кожної команди
- Графік зміни odds з часом
- Топ ставки по матчу (соціальний елемент)
- Одна дія: ввів суму → підтвердив

### Портфоліо
- Всі відкриті позиції
- P&L в реальному часі
- **Кнопка "Продати зараз"** — вийти достроково. Це вбивча фіча проти Bet365

### Leaderboard
Хто найбільше заробив на турнірі. Вірусний механізм.

## Технічний стек

Максимально швидко, мінімум ризиків:

- **Frontend:** Next.js + Tailwind (1 розробник, 1-2 тижні)
- **Auth/Wallets:** Privy — найлегший onboarding для не-крипто юзерів
- **Дані:** Polymarket Gamma API — готові ринки, odds, об'єми
- **Ордери:** `@polymarket/clob-client-v2` — офіційний SDK
- **Builder code:** одна строчка в кожному ордері
- **Деплой:** Vercel (безкоштовно)

Готові open-source демо від Polymarket покривають 80% технічної роботи.

**Залежність від Polymarket** — вони можуть змінити умови. Рішення: не критично для короткострокового проекту.
